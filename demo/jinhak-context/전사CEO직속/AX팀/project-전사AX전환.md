# 프로젝트: 전사 AX 전환

> ⚠️ 서비스 설명은 공개 정보 기반 정리입니다. 사내 최신 수치/전략으로 보완하세요.

## 목표
"더 똑똑한 AI를 사는 게 아니라, **우리 회사를 아는 AI를 만든다.**"
진학사의 4대 서비스 전반에 AI를 내재화하고, 이미 보유한 Microsoft 365(SharePoint) 위에
추가 비용 없이·안전하게(읽기 전용·권한 분리) 회사 맥락/데이터 인프라를 구축한다.

## 진학사 4대 서비스 — AX 대상 도메인
AI 전환은 각 서비스의 핵심 업무를 기준으로 한다.

### 1. 진학닷컴 — 입시정보·합격예측
- 모의지원/합격예측을 국내 최초 개발, 최고 수준 적중률 보유.
- 수시·정시 합격예측, 학생부 AI진단(AI점수). → **AX 우선순위 최상** (별도 프로젝트로 모델 고도화)
- AX 기회: 입시 데이터 분석 리포트 자동화, 상담 콘텐츠 생성 보조.

### 2. 진학어플라이 — 대학 원서접수 플랫폼
- 대한민국 대표 공통원서 플랫폼. 전국 270여 개 대학 원서접수 + 합격자·입학관리 시스템.
- AX 기회: 원서접수 피크 시즌 CS 문의 분류·요약, 대학별 모집요강 비교표 자동화.
- 보안 주의: 지원자 개인정보(주민번호·연락처) 산출물 노출 절대 금지.

### 3. 캐치 — 취업·채용
- 추천기업·직무 중심 취업정보 서비스(2015~). 'CATCH 멤버십' 구독형 채용·브랜딩.
- AX 기회: 채용공고/기업정보 정리 자동화, 직무 콘텐츠 생성 보조.

### 4. 블랙라벨 — 교육콘텐츠
- 1등급 학생이 많이 보는 수학 참고서 등 차별화 교재.
- AX 기회: 문항·해설 콘텐츠 제작 보조, 교재 기획 리서치.

## 3-Layer 인프라 구조
- **1층 회사 맥락**: 본부/팀/프로젝트 목표를 AI에 자동 주입 (이 폴더가 그 콘텐츠)
- **2층 데이터 접근**: SharePoint/Teams 등 4대 서비스 공유문서를 읽기 전용 연결
- **3층 도구**: jinhak-harness npm 패키지 (6개 AI 호스트 자동 등록) — 핵심 완성

## 현재 상태 (2026-06)
- 3층 도구: ✅ 핵심 완성 (v0.1.3, 12개 슬래시 커맨드)
- 1층 컨텍스트: ⏳ 설계 완료, SharePoint 연결은 IT admin consent 대기
- 2층 데이터: ⏳ 인터뷰 모드 구현, MCP 연동은 admin consent 대기
