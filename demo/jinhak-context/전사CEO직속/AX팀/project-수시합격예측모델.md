# 프로젝트: 수시 합격예측 서비스 모델 개발

> ⚠️ 기능 설명은 진학닷컴 공개 서비스 정보 기반 정리입니다. 사내 모델 스펙으로 보완하세요.

## 목표
진학닷컴 **수시 합격예측 서비스의 'AI점수'** 를 차세대 모델로 고도화하여
적중률과 학생부 분석 품질을 끌어올린다.

## 서비스 현황 (무엇을 제공하는가)
진학닷컴은 모의지원/합격예측을 국내 최초로 개발했고, 수시 합격예측에서 자체 AI로
**학생부를 분석·수치화하는 'AI점수'** 를 제공한다.

### 수시 AI점수 — 3종 분석
종합전형 모의지원·합격예측 리포트에서 다른 지원자들과 비교 가능한 형태로 제공:
- **학생부 AI점수** — 학생부 전반의 경쟁력 종합 수치
- **교과 AI점수** — 교과(성적) 기반 경쟁력
- **비교과 AI점수** — 자체 개발 AI가 비교과 내용을 분석·수치화

### 학생부 AI진단 세부 기능
- **비교과 우수 문장** — 비교과 기록 중 강점 문장 추출
- **비교과 유사도 분석** — 다른 지원자 대비 내용 유사도 분석
- **나의 위치 / 동일 등급대 성적 분포** — 결제 시 전체 분석 결과 제공

### 제공 형태
- **무료**: 전년도 기준 수시 합격가능성 확인
- **유료(결제)**: 나의 위치·등급대 분포·비교과 분석(긍정 문장, 유사도) 등 전체 리포트

## 모델 개발 목표 (AX팀)
1. **적중률 향상** — 합격예측 정확도 baseline 대비 개선
2. **학생부 AI진단 품질** — 교과/비교과 분석의 정밀도·설명가능성 강화
3. **안전성** — 학생 개인정보·성적은 학습/산출물에서 엄격 분리, 편향 점검

## 데이터·보안 주의
- 학생부·성적·개인식별정보는 **confidential** 등급 → 로컬 캐시 금지(메모리 only) 원칙
- 외부 LLM 전송 시 사용자 동의 절차 필수 (정보보안팀 협의)

## 현재 상태 (2026-06)
- 서비스 운영 중(진학닷컴), 차세대 모델 고도화 기획 단계
- 데이터 접근(2층)·평가셋 수집은 보안팀 협의 후 진행
