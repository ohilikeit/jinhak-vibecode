# /start — 직군 인터뷰

직군·반복 업무·결과물·말투·도구 5문항으로 사용자 프로필을 만들고, 8 행동 차원(상세도/속도/실수 무관용/협업 성향/기록 선호/도구 친숙도/검증 강도)을 자동 추론합니다. **한 번만** 답하면 됩니다.

## 실행

```bash
npx -y jinhak-harness start
```

이 명령은 stdin으로 5개 답변을 받는 대화형 프로그램입니다. 채팅에서 한 질문씩 사용자에게 묻고 답을 모은 뒤, 한 번에 줄바꿈으로 구분해 stdin에 전달하세요.

저장 위치: `~/.harness/user-profile.md` (YAML frontmatter + 본문).

## 이미 인터뷰를 끝낸 경우

기존 프로필이 있으면 자동으로 건너뜁니다. 다시 받고 싶다면 `~/.harness/user-profile.md` 를 삭제 후 재실행.
