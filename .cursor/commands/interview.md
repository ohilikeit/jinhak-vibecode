# /interview — 개인 컨텍스트 심화 인터뷰 (full 모드)

`/start`(5문항 직군 프로필)보다 깊이 들어가, **우선순위·어조·반론 방식·기본 언어·다루지 않을 주제** 같은 개인 컨텍스트를 모읍니다. 이 컨텍스트는 저장 후 **매 세션 시작 시 AI에 자동 주입**되어, 매번 다시 설명하지 않아도 "회장님(또는 본인)을 아는 AI"처럼 동작합니다.

- CORE 7문항 — 직군 불문 누구에게나 적용
- `--exec` — 임원/경영진용 질문팩 추가(언론 키워드·경쟁사 동향·일일요약/주간성찰 시간, 총 11문항)
- `--force` — 기존 컨텍스트를 덮어쓰고 다시 진행

이 기능은 eco가 아닌 **full 모드**로 동작합니다 — 압축 요약이 아니라 전체 개인 컨텍스트를 항상 주입해 context가 늘 잘 동작하도록 합니다. (심화 인터뷰가 없으면 `/start` 프로필 기반 압축 다이제스트로 폴백.)

## 실행

```bash
npx -y jinhak-harness interview
```

이 명령은 stdin으로 답변을 받는 대화형 프로그램입니다. 채팅에서 한 질문씩 사용자에게 묻고, 모은 답을 줄바꿈으로 구분해 stdin에 전달하세요. 선택형(어조·반론·언어)은 번호로 답합니다.

저장 위치: `~/.harness/personal-context.md` (YAML frontmatter + 본문).

## 주입 메커니즘

- `session-start` 훅이 `bin/render-digest.js`를 호출 → 저장된 컨텍스트를 읽어 부트스트랩에 합성합니다.
- full 모드를 끄려면 `HARNESS_CONTEXT_MODE=eco` 환경변수로 압축 다이제스트만 주입할 수 있습니다.
- 모든 답변은 이 기기에만 저장됩니다(baseline 정책). 단, 주입된 컨텍스트는 실행 중인 AI 호스트로 전송됩니다(컨텍스트가 동작하려면 필요).

## 이미 끝낸 경우

기존 `personal-context.md`가 있으면 자동으로 건너뜁니다. 다시 받으려면 `--force` 또는 파일 삭제 후 재실행.
